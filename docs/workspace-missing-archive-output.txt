Native failure coverage
  Initial root-removal intent survives a failure before unlink. Ordinary retry
  refuses a present root even when device/inode/mode happen to match.
  Current-empty-directory disposition binds original transfer, freeze, reap,
  removal intent, allocation, fixed parent and current directory observation.
  It refuses symlinks, nonempty roots, changed identity, changed authority,
  changed parent, malformed or noncanonical approval, and mismatched digest.
  Once a disposition attempt starts, a present path needs fresh approval;
  exact replay may confirm absence only. It grants no lease, quota release or
  completed-reap result. CLI tests reject socket/token flags even when empty.
  Fixed-helper validation and retirement tests preserve ordinary allocation,
  verification and release behavior and reject changed managed caps/evidence.
