## What these docs are

These are pre-release docs. They describe what the source on the `main` branch does, and they
are written from the repository's own README, its `docs/` folder, the `bench` and `benchd` help
and the API code. Where the repository says something is partial or unverified, so do these
pages. They will be refreshed at the first release.

<WetPaint>
  SuperBench is an experimental single-host prototype for trusted repositories. Leases are
  cooperative, nothing in it isolates untrusted code, and there is no supported installation.
  [Status](/start/status/) lists what is done, what is partial and what is not built.
</WetPaint>

For agents, the same docs are plain text: [`/llms.txt`](/llms.txt) indexes them, and
[`/llms-full.txt`](/llms-full.txt) is every page in one file.
