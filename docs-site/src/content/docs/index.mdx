## What these docs are

These docs describe SuperBench v0.0.1, the first release, tagged on 2026-11-22. They are written
from the repository's own README, its `docs/` folder, its changelog, the `bench` and `benchd`
help and the API code at that tag, and the build checks them against the source on `main`. Where
the repository says something is partial or unverified, so do these pages.

<WetPaint>
  SuperBench v0.0.1 is an experimental single-host release for trusted repositories, not
  production software. Leases are cooperative, nothing in it isolates untrusted code, and it runs
  on one host. [Status](/start/status/) lists what is done, what is partial and what is not built.
</WetPaint>

For agents, the same docs are plain text: [`/llms.txt`](/llms.txt) indexes them, and
[`/llms-full.txt`](/llms-full.txt) is every page in one file.
